# Đánh giá VTT và tổng hợp TTS — 2026-11-16

## Cấu hình lần chạy

- Hệ điều hành: Windows; 12 logical processors; 4 worker TTS, ngân sách 12 intra-threads tự chia thành 3 thread/worker.
- Model: Turbo local tại `Models/v3turbo` (10 files, 210,556,603 bytes); cache model được phép lưu dưới `Models/tts/v3turbo`.
- G2P: `Models/g2p_bridge/g2p_bridge.exe`, một bridge process cho mỗi worker.
- ONNX Runtime: package Windows x64 1.22.0 chính thức, tạm giải nén để chạy lần đánh giá rồi xóa. DLL cài sẵn trong `C:\Windows\System32` là 1.17.1, không tương thích với `ort 2.0.0-rc.10` (yêu cầu 1.22.x).
- Time-stretch: WSOLA trong RAM; output mono PCM16, 48 kHz. Không ghi output audio.
- Một lượt thử trước đó dùng sai ngân sách `threads=4` (một intra-thread/worker), đã dừng và loại khỏi báo cáo. Bảng dưới đây chỉ ghi lượt chạy hoàn chỉnh với cấu hình tự chia 12/4.

## Cấu trúc dữ liệu

Cả bốn file là WebVTT; ba file `.merged.zh.vi.vtt` có cue IDs tùy chọn và settings ở dòng timestamp. Trong 272 cue, 211 cue có setting `line:`: 32 cue `line:20%`, 179 cue `line:90%`; 61 cue không khai báo `line`. Không có setting decimal hoặc sai cú pháp trong input. Không phát hiện cue nào chứa đồng thời ký tự chữ Hán và dấu tiếng Việt trong bộ mẫu.

## Lệnh và cách tái lập

Harness: `cargo build -p vieneu-tts --example evaluate_vtt`, sau đó chạy `target\debug\examples\evaluate_vtt.exe` từ workspace root, không truyền tham số. Harness mặc định xử lý bốn file trong `input/`, cấu hình `num_workers(4)`, để `threads` tự lấy số CPU khả dụng và chỉ in metrics (không lưu audio).

Trong lần chạy này, `ORT_DYLIB_PATH` trỏ tới `onnxruntime.dll` của package Windows x64 1.22.0 tạm giải nén; `PATH` có thư mục `lib` cùng package. Cần runtime ONNX 1.22.x tương thích để tái lập. Lệnh kiểm tra hash sau chạy là `Get-FileHash -Algorithm SHA256` trên các file `.vtt` trong `input/`.
